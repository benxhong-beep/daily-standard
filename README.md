# The Daily Standard — V1

90-day accountability PWA with daily checklist, calendar, evening review, goal editing, Sunday planner, and individual relationship reflection.

## Publish from iPhone
1. Create a private GitHub repository (e.g. `daily-standard`).
2. Upload the four files in this folder to the repository root.
3. In Cloudflare Pages, connect GitHub and deploy this repository as a static site (no build command; output directory `/`).
4. Open the resulting HTTPS address in Safari, Share > Add to Home Screen.

## Important
All data is stored in localStorage on **each device**. There is no login, cross-device sync, or shared couples account yet. Export backup JSON regularly. Do not clear Safari website data. Free hosting and free-tier limits may change.
